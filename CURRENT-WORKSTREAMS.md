## Contributing via GitHub

Pull requests follow the same pattern as [charter review](./wg-charter/charter.md):

1. Open a PR with proposed changes.
2. Discuss in threaded comments; use suggestion blocks where helpful.
3. Resolve threads when the group agrees. **Merge at the discretion of the lead or chair**, after sufficient time is allowed for comment. Status reviewed during WG meetings.

For charter-level scope, see [wg-charter/charter.md](./wg-charter/charter.md).

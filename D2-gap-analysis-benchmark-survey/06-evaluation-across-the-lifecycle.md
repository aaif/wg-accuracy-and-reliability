# 6. Evaluation Across the Lifecycle

> Status: outline (carried over from the running notes)

| Stage | Focus |
|---|---|
| Research and selection | Model/task fit, benchmark relevance, quality–cost trade-offs |
| Development and integration | Grounding, tools, routing, agent communication, state management |
| Pre-production validation | End-to-end testing, perturbation, concurrency, recovery |
| Deployment and operations | Release traceability, drift, failure detection, outcome verification |
| Recovery and improvement | Retry, resume, compensate, escalate, and convert incidents into tests |

## Four main questions

1. What decisions are practitioners making?
2. What reliability evidence do they need?
3. What benchmarks or methods currently provide that evidence?
4. What remains missing or does not transfer to the next stage?

> **Proposal (for discussion):** answer these four questions as [question cards](cards/), grouped by the stages above. Each card links a use-case pattern (§4) and requirement (§5) to what exists today, typed gaps (§8) and the next deliverable (§9).
